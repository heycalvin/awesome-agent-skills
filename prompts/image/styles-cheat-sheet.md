# 生图核心关键词与风格速查表 (Image Prompt Styles Cheat Sheet)

本速查表汇总了文生图（Midjourney、Flux、Stable Diffusion、DALL-E 等）中经过广泛验证的高频效果词，支持中英双语检索与组合。

---

## 1. 艺术风格与媒介 (Art Mediums & Styles)

| 英文关键词 | 中文说明 | 视觉特征与适用场景 |
| :--- | :--- | :--- |
| `cinematic film still` | 电影剧照 | 宽银幕比例、胶片质感、叙事感极强 |
| `editorial fashion photography` | 时尚杂志大片 | 高对比度、高级质感、前卫构图 |
| `isometric 3D render, octane render` | 等轴测 3D 渲染 | 游戏场景、微缩模型、精致粘土或玻璃质感 |
| `flat vector illustration` | 扁平矢量插画 | 纯色块、利落线条、现代 UI 插画 |
| `vintage risograph print, dot screen` | 孔版印刷 / 复古网点 | 限制墨色、复古纹理纸、复古波普风格 |
| `cyberpunk concept art, neon glow` | 赛博朋克概念艺术 | 霓虹光晕、高科技低生活、冷暖撞色 |
| `watercolor wash, dripping ink` | 水彩渲染 / 墨迹泼洒 | 柔和边缘、水渍晕染、东方式留白意境 |
| `analog 35mm photograph, kodak portra 400`| 35mm 胶片摄影 | 真实颗粒、自然暖调肤色、怀旧纪实 |

## 2. 光影质感 (Lighting & Atmosphere)

| 英文关键词 | 中文说明 | 视觉效果 |
| :--- | :--- | :--- |
| `volumetric lighting / god rays` | 丁达尔光 / 体积光 | 光束穿透烟雾或树林，营造神圣神秘氛围 |
| `golden hour sunlight` | 黄金时刻晨昏光 | 柔和温暖的斜射金光，拉长投影，人像绝佳 |
| `moody dramatic Rembrandt lighting` | 伦勃朗光 / 戏剧阴影 | 侧光在阴影脸颊形成标志性三角形高光，深邃立体 |
| `bioluminescent glow` | 生物自发光 | 荧光深海生物、梦幻阿凡达风格植物发光 |
| `soft diffused studio light` | 柔和影棚散色光 | 消除生硬暗影，展现细腻商品或模特皮肤细节 |
| `backlit / rim light` | 逆光 / 轮廓边缘光 | 勾勒主体身形发丝，将主体从暗色背景中分离 |

## 3. 镜头焦段与构图 (Lens & Composition)

| 英文关键词 | 中文说明 | 效果 |
| :--- | :--- | :--- |
| `extreme close-up (ECU), macro detail` | 微距极特写 | 强调眼眸纹理、雨滴、微小机械齿轮细节 |
| `85mm portrait lens, f/1.2 shallow depth of field` | 85mm 人像定焦虚化 | 虚化杂乱背景（奶油般光斑 bokeh），突出人脸 |
| `24mm wide angle lens, dynamic perspective` | 24mm 广角动态透视 | 建筑张力、街头沉浸感、拉长空间线条 |
| `low angle shot (worm's eye view)` | 仰拍低视角 | 增强主体的崇高感、压迫感或英雄气概 |
| `bird's eye view / drone aerial photography` | 鸟瞰视角 / 无人机航拍 | 宏观地形、对称城市街区、纵观全局 |
| `rule of thirds / golden ratio composition` | 三分法则 / 黄金分割 | 和谐稳定的视觉平衡与焦点指引 |

---

## 4. 材质与高保真修饰词 (Textures & Quality Modifiers)

- **质感**：`ultra-detailed skin pores`（细腻毛孔）, `brushed titanium metal`（拉丝钛金属）, `frosted translucent glass`（磨砂毛玻璃）, `crumpled kraft paper`（揉皱牛皮纸）
- **色彩搭配**：`monochrome palette`（单色调）, `analogous color harmony`（邻近色调和）, `duotone cyan and orange`（青橙撞色）
- **通用画质词（建议克制使用）**：`8k resolution, photorealistic, masterpieces, fine art, Unreal Engine 5 render`
